# LibSpace — Платформа для авторов и читателей

![Python](https://img.shields.io/badge/python-3.11+-blue.svg)

**LibSpace** 0 это современная веб-платформа для публикации и чтения книг. Проект объединяет авторов и читателей, предоставляя удобный интерфейс для создания произведений, отслеживания прогресса чтения и детальной аналитики вовлеченности аудитории.

---

## 🚀 Основной функционал

### 📖 Для читателей (Библиотека и чтение)
* **Продуманная читалка:** Настройка шрифтов, фона, сохранение прогресса чтения (запоминание последней прочитанной главы и процента).
* **Пользовательские полки:** Разделение книг по статусам («Читаю сейчас», «Буду читать», «Прочитано») и создание собственных коллекций.
* **Умная система уведомлений:** Оповещения о выходе новых глав в избранных книгах.
* **Социальное взаимодействие:** Оценки, комментарии к главам и рецензии на книги.

### ✍️ Для авторов (Кабинет автора)
* **Управление контентом:** Создание книг, удобный текстовый редактор для глав, настройка обложек и метаданных (жанры, теги).
* **Система статусов:** Черновики, публикация в процессе, завершенные произведения, модерация.
* **Развернутая аналитика:** 
  * Отслеживание просмотров и уникальных читателей (за разные периоды).
  * Воронка дочитываемости (отслеживание процента отвалов аудитории по главам).
  * Графики удержания и активности читателей.
* **Монетизация (в планах):** Подписки, платные главы, система донатов.

---

## 🛠 Технологический стек

* **Backend:** Python (Django)
* **База данных:** SQLite / Django ORM
* **Frontend:** Шаблонизатор от Django

## ⚙️ Установка и локальный запуск 

**1. Клонирование репозитория:**
```bash
git clone [https://github.com/Dxd5642/online-library.git](https://github.com/Dxd5642/online-library.git)
cd your-repo-name
```

2. Настройка переменных окружения:
Скопируйте файл .env.example в .env и укажите необходимые параметры.
```Bash
cp .env.example .env
```

3. Применение миграций базы данных:
```Bash
python manage.py makemigrations
python manage.py migrate
```

4. Создание администратора
```Bash
python manage.py createsuperuser
```

5. Запуск проекта
```Bash
python manage.py runserver
```

После успешного запуска приложение будет доступно по адресу: http://localhost:8000 (по умолчанию).
